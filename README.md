# NirTC — Personal Portfolio

Responsive portfolio for Niranjan Rao (NirTC), with a light/dark theme toggle.

The `assets/` folder contains the uploaded GitHub, YouTube, and Discord logos used by the social cards. Keep this folder alongside `index.html` when deploying.

## Social links to verify
- GitHub: `https://github.com/NirTC`
- YouTube: `https://www.youtube.com/@NirTC`
- Discord currently links to the Discord homepage; replace it with Niranjan's actual invite/profile URL.

## Publish with GitHub Pages
Upload `index.html` and the complete `assets/` folder to the root of a GitHub repository. Then open **Settings → Pages**, select the `main` branch and `/ (root)`, and save.
